## نتایج راستی‌آزمایی نهایی (این اجرا)

- تست‌های امنیتی: **۳۸/۳۸ موفق** — شامل IDOR کامل، قانون ۲۴ ساعت (423)، Workflow، CSRF، MIME validation، Signed URL، Audit scope
- تست‌های هوش صوتی: **۵/۵ موفق** — خرید، انتقال، امانت، اطلاعات ناقص (Progressive Clarification)، چند قلم
- تست تاریخ ورود (تقویم شمسی): **۵/۵ موفق** — ذخیرهٔ امروز، رد تاریخ آینده (422)، رد فرمت نامعتبر، فیلتر بازهٔ تاریخ، بازگشت بدون انحراف منطقهٔ زمانی
- تبدیل جلالی: رفت‌وبرگشت ۲۰۰۰ روز پیوسته بدون خطا + طول ۳۶ ماه معتبر + نوروزهای ۱۴۰۳-۱۴۰۵
- TypeScript: کد پروژه بدون خطا
- مرورگر: ورود → خانهٔ سرپرست → فرم ثبت با «تاریخ ورود مصالح» → پاپ‌آپ تقویم شمسی → ذخیره → جزئیات → فیلتر تاریخ در ثبت‌ها؛ همه بدون خطای کنسول

## قابلیت‌های تازه (این اجرا)

- **تقویم شمسی پاپ‌آپ** (`JalaliCalendarSheet`): شنبه‌شروع، ارقام فارسی، ناوبری ماه RTL (راست = ماه قبل)، انتخاب سریع امروز/دیروز، جلوگیری از تاریخ آینده
- **فیلد «تاریخ ورود مصالح»** در فرم ثبت (دستی و صوتی) — پیش‌فرض امروز، ذخیره در DB (`deliveryAt`)، نمایش جلالی در جزئیات ثبت
- **فیلتر بازهٔ تاریخ** در صفحهٔ ثبت‌ها (از تاریخ / تا تاریخ) با همان تقویم پاپ‌آپ
- **تعمیر باگ تبدیل جلالی→میلادی** در `fa.ts` (فرمول استاندارد jdf) — Grid روزها اکنون کاملاً مرتب
- ممیزی RTL: ارقام فارسی در فیلد مقدار، جداکنندهٔ هزارگان فارسی (٬)، `dir="ltr"` هدفمند فقط برای محتوای لاتین
